# Image Classification Using Deep Learning — MobileNetV2

## 📌 Project Overview
This project uses deep learning and transfer learning to classify images into two categories: **Cat** and **Dog**. It uses the pretrained MobileNetV2 model with TensorFlow/Keras to make image classification more efficient.

## 🎯 Objectives
- Build an image classification model using MobileNetV2.
- Preprocess and resize images for model training.
- Train and evaluate the model using training and validation datasets.
- Predict whether an uploaded image contains a cat or a dog.

## 🛠️ Technologies Used
- Python
- TensorFlow and Keras
- MobileNetV2
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## 📂 Dataset
The project uses the Cats vs Dogs image dataset provided through TensorFlow Datasets.

- **Classes**: Cat and Dog
- **Image size:** 224 × 224 pixels
- **Data split:** 2,000 training images and 500 validation images in the final streamlined version of the notebook.

## ⚙️ Project Workflow
1. Load the Cats vs Dogs dataset.
2. Explore sample images and their labels.
3. Resize and preprocess images.
4. Load the pretrained MobileNetV2 model using ImageNet weights.
5. Add classification layers for cat and dog prediction.
6. Train the model and monitor training and validation accuracy.
7. Evaluate performance using a confusion matrix and classification report.
8. Upload an image and predict its class with a confidence score.

## 📊 Results
- **Validation accuracy:** 93.60%
- **Validation loss:** 0.3065
- **Evaluation metrics:** Precision, recall and F1-score.
- **Visualization:** Training accuracy graph and confusion matrix.

## 🚀 How to Run
1. Open the notebook `Image_Classification_MobileNetV2.ipynb` in Google Colab.
2. Run the cells in order to install dependencies, load the dataset, preprocess images, build the model and evaluate it.
3. Upload a cat or dog image in the prediction cell to test the model.
